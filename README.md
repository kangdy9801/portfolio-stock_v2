# FOLIO v5 — 주식 포트폴리오 · 매크로 경제 · 무역/산업 시차 분석

GitHub Pages에서 실행하는 개인 투자 연구 대시보드입니다. **2026년 8·9월 수출입동향과 2026년 7·8월 산업활동동향 공식 PDF의 확인된 데이터를 초기값으로 내장**했습니다. 종전 2026년 4월 산업활동 기록도 이력으로 유지하며, 2026년 5월 소비자물가 PDF는 **독립 분석**용으로 내장했습니다. 사용자가 업로드한 PDF 원본은 배포 ZIP에 포함되지 않습니다.

## 주요 기능

1. **나의 포트폴리오** — CNN 미국 Fear & Greed 반원 게이지, 7가지 지표·히스토리, 한국/미국 주식·ETF 종목 검색, 수량·평단·평가액·손익·섹터비중, 종목 클릭 시 PER/PBR/ROE/EPS 등 재무정보. 매일 종가 데이터는 GitHub Actions 실행 성공 후 표시됩니다.
2. **섹터 비교(재무제표)** — 한국/미국 업종별 PER/PBR 중앙값, 기업 3개 비교, PER×PBR 산점도, 기업별 수익성·재무제표. 미수집 지표는 빈칸으로 남습니다.
3. **장기 프로젝트·배당** — 장기 적립 목표, 원금·평가액 구분, 월·연 배당 예측과 실제 입금, 국내·해외 원천징수·수수료, 연간 해외주식 매도손익·양도세 별도 간이계산. 입금 기록은 직접 입력합니다.
4. **무역·산업 분석·PDF** — 사용자 요청에 따른 `수출입 월 t ↔ 산업활동 월 t-1`을 쌍으로 분석합니다. 별도로 `8→9월 수출입`과 `7→8월 산업활동`을 계산하며, 20개 수출 섹터의 월별 금액·증감, 수입 항목, 석유화학·석유제품 물량/단가 변화, 업종별 생산·출하 방향의 일치/반대/비교보류를 표시합니다. **소비자물가동향은 독립 화면으로 분리**합니다. 월 선택, PDF 추가·수정본 버전 이력, JSON 백업이 가능합니다.

## GitHub Pages 신규 배포

1. ZIP을 풀어 `index.html`, `assets/`, `data/`, `scripts/`, `.github/`, `.nojekyll`, `requirements.txt`를 GitHub 공개 저장소 루트에 업로드합니다. **ZIP 파일 자체를 업로드하지 마세요.**
2. 저장소의 `Settings → Pages → Build and deployment → Source`에서 **GitHub Actions**를 선택합니다.
3. `Actions → Update Stock Prices and Deploy` 워크플로를 수동 실행합니다. GitHub Actions 권한에서 `Read and write permissions`가 필요한 경우 활성화합니다.
4. `https://깃허브아이디.github.io/저장소명/` 에서 열 수 있습니다. HTML만으로도 6개의 공식 보고서 초기 분석을 볼 수 있으며, 시장 종가·경제 일정 갱신에는 Actions 성공이 필요합니다.

## 매달 PDF 추가 방법

1. 사이트 좌측 `무역·산업 분석·PDF` → `매월 보고서 추가`를 클릭합니다. 최대 25 MB PDF를 선택합니다.
2. PDF.js가 브라우저에서 PDF 앞부분을 읽어 **보고서 종류, 통계 기준월, 주요 수치 및 일부 섹터**를 추출합니다. 표 구조·스캔 여부에 따라 자동 인식률이 달라질 수 있습니다. 직접 입력 버튼도 있습니다.
3. `추출값 검토` 창에서 원문과 **수출액/수입액/전월비/전년비/품목금액·단위**를 대조하고, 자동 누락된 업종은 `섹터명 | 지표명 | 수치 | 전년동월비` 형식으로 보완한 뒤 저장합니다.
4. 저장한 수치 기록은 사용하는 **브라우저의 localStorage**에 누적됩니다. 같은 기준월의 수정본은 새 버전으로 기록되고, 이전 기록은 삭제되지 않으며 기록표에서 선택할 수 있습니다.
5. 데이터는 자동으로 다른 기기와 동기화되지 않습니다. `경제보고서 JSON 백업` 및 포트폴리오 `전체 JSON 백업`을 정기적으로 보관하세요.

**중요:** PDF 파일은 브라우저 안에서 처리되고 서버로 전송되지 않습니다. 원본 PDF 자체가 GitHub에 업로드되는 것도 아닙니다. 원본 PDF를 별도로 보관해야 원문 대조가 가능합니다. PDF.js 라이브러리를 CDN에서 불러오므로 첫 PDF 열람에는 인터넷 연결이 필요합니다.
